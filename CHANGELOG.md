# Changelog

All notable changes to Delta (Δ) will be documented in this file.

The format is based on Keep a Changelog (https://keepachangelog.com/en/1.0.0/).

## [Unreleased]

### Added
- Core compiler pipeline: lexer, recursive descent parser, semantic resolver, emitter
- Six core constructs: patch, fix, intent, migrate, guard, trace
- CLI via Commander.js with preview and apply modes
- Language Server Protocol (LSP) implementation
- Language adapters for TypeScript, Python, and Rust (initial support)
- Tree-sitter integration for multi-language parsing
- TypeScript Compiler API integration
